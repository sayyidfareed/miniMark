miniMark Support

A small, native Markdown editor for the Mac. Requires macOS 14 or later.

Contact

Email support@ideius.com. Please include your macOS version, your miniMark version (miniMark menu, About miniMark) and what you did before the problem appeared. Do not attach private documents unless you want us to see them.

Set miniMark as your default Markdown app

  1. In Finder, select any .md file.
  2. Choose File, then Get Info (or press Command-I).
  3. Under Open with, choose miniMark.
  4. Click Change All, then confirm.

Images next to my document do not show

The Mac only lets miniMark read files you have allowed. When the preview finds pictures in the document’s folder, miniMark asks you to choose that folder once. After you do, the pictures appear and macOS remembers the choice.

What the preview supports

Headings, bold, italic, strikethrough, links, images, lists, task lists, tables, quotes, code blocks, footnotes, LaTeX math with $…$ and $$…$$, and Mermaid diagrams in mermaid code blocks.

Export and print

File, Export saves TXT, RTF or HTML. File, Print opens the standard Mac print sheet, where you can choose Save as PDF. Math and diagrams appear in HTML and PDF; the RTF export keeps math as its source text.
